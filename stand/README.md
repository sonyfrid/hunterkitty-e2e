# Стенд

Локальная копия сервера Mini App для автотестов. Код стенда закрыт вместе с продуктом, здесь только описание.

- Тот же aiohttp-сервер Mini App, что в проде, на отдельной локальной базе Postgres.
- Тестовые данные: 17 выдуманных вакансий на «Тестовой площадке» и 4 пользователя (`support/users.js`): новичок, тестировщик, второй пользователь для проверок доступа, отключённый.
- Токен бота фейковый: в Telegram и на сайты вакансий не уходит ни одного запроса, фоновый поиск не запускается.
- `POST /__e2e/reset` пересоздаёт данные; фикстура `api` вызывает его перед каждым тестом.
- Адрес по умолчанию `http://127.0.0.1:8099`, переопределяется через `STAND_URL`.
